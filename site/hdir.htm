This screen is an example of HotDIR capabilities. The descriptions which are displayed on the right of the screen are determined in real-time when HotDIR scan the directory. The syntax of HotDIR is the same than the DOS DIR command. As you can see, HotDIR is capable of determining SFX progs, names of modules, etc... Of course, you can change all the colors if you don't like the default ones.




Last version of HotDIR: HDIR214a.ZIP (39,898 bytes)

Features:

  • Some bugs fixed since release 2.0.
  • Real-time informations on each recognized file
  • Can display the size of each directory
  • Can display the real disk occupation (like 4DOS)
  • Can display files in low-case, hi-case, name-case (like the screen capture above)
  • Possibility to increase capabilities of HDIR by editing HDIR.INI description file
  • MAC floppies recognition (name, total size and free space)
  • ATARI floppies recognition
  • Non-formatted floppies enhanced recognition (faster than DIR)
  • Display the name of the OS which has formatted a floppy (eg: WIN4.0, MSDOS5.0, ...).
  • OS/2 compatible
  • Windows 3.x, 95 & NT compatible
  • Minimum requirement: 80386 and about 94k of free conventional memory
