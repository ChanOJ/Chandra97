What's new in H-DIR

         v2.0b Display runtimes entirely codded in BASM.
               Little modification of the /L and /Z switches.
               HDIR.CFG is dead. Long life to HDIR.INI !!!
               The OS of the disk is now displayed in the low-right corner.
               Non formated disk access bug fixed (6s -> 4.5s).
               ATARI (non auto-boot) and MAC HD floppies are now recognised.
               The infos which where displayed with the /I switches are now
               in the HDIR.DOC file. The /I switches is now dedied to set
               the level of information displayed by HDIR about each file.

          v2.0 SyQuest-name-under-Win95 bug fixed
               NO NAME bug fixed
               HDIR.INI is now limited to 20000 chars instead of 511 lines
               Memory consummation reduced

          v2.1 Bugs in Mac names fixed
               Display the size and the free space of mac floppies
               Bug in text mode fixed (line of #0 chars replaced by #20)
               Bug in comparing header fixed
               Now values 1 to Z are accepted for "Number" variable
               Doc is now in english (american ?;)
               Modification of /Z and /I switches (+ bugs fixed)
               A,B,C,... fields added to HDIR.INI.
               HDIR.INI v2.1 is no more compatible with old HDIR.INI (Comment
               structure modified)

         v2.11 Minor changes
               Doc modified

         v2.12 Minor changes
               Doc modified

         v2.13 When a file can't be open, an * is now displayed near the size
               Bug in the pause-between-screen function fixed

         v2.14 . and .. dirs are no more counted as directories
               VCD & SAVEDIR are now included in the H-DIR pack

         v3.0b Mac-floppies-name-bug-fixed
               Famous bug bad-interpreting-of-size-when-real-sizing fixed
               The sizes of the directories are now displayed in "real-time"
                 when the /Os option isn't specified
               The . and .. directories are no more displayed
               ^T and ^R function added in the HDIR.INI "Header" field
               Some bugs with the "Text" option computing fixed
               HDIR.INI really improved
               "Error 201" bug with percents fixed
               File limit is now 1200 (instead of 999)

Of course, at each release of H-DIR, the HDIR.INI file is also ehanced and become
more performant. It knows now (r1.51) about 151 different types of files.
