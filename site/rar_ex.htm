The difference between the two sizes represent 48 seconds of download with a good 14.400.

The command line used for PKZIP was : PKZIP -ex
The command line used for RAR was :   RAR a -s
As you can see, PKZIP was used with its better compression method but RAR wasn't (method 3/5 is set as default).

The -s switches used for RAR is named "Solid archiving". The principle is to use only one dictionnary for all the archive (it is very efficient with text but less with random datas).

RAR can be used on the command line, but a text interface is also included. This interface can also read and extract (using the appropriate unarchiving program) PKZIP, ARJ and LHA archives.

RAR also exists under OS/2, Win95, Win32S, Linux, UNIX and AMIGA systems (see the FTP site).
